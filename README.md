# gym-membership-data-analysis

SQL project for analyzing gym membership data using MySQL.

## Project Overview

This project analyzes gym membership data using MySQL to understand member behavior, membership types, attendance patterns, and gym usage.

The dataset contains information such as age, gender, membership type, weekly visits, attendance days, fitness activities, sauna usage, and favorite drinks.

## Dataset

- Source: Kaggle
- Database: MySQL
- Table: gym.gym_membership

## Tools Used

- MySQL
- MySQL Workbench
- SQL

## SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- LIMIT
- LIKE
- BETWEEN
- COUNT()
- AVG()
- MAX()
- Subqueries

## Analysis Performed

- Total number of gym members
- Male and female member distribution
- Average age of members
- Members above the average age
- Members by membership type
- Oldest and youngest members
- Average age by membership type
- Sauna users
- Members visiting more than 3 times per week
- Premium members sorted by age
- Maximum weekly visits
- Favorite drink preferences
- Members aged between 25 and 40
- Monday attendance
- Saturday attendance

## Conclusion

This project helped me practice SQL and understand how to analyze gym membership data using MySQL. It helped identify patterns related to membership types, member age, attendance, activity levels, and gym usage.
